## Course overview

This course introduces the representation and analysis of continuous-time and discrete-time signals and systems. Topics include signal operations and properties, system classification, linear time-invariant (LTI) systems and convolution, Fourier series, the Fourier transform, the Laplace transform, and sampling theory. An introductory MATLAB lecture supports numerical computation and signal visualization.

## Study guide

1. Begin with Lecture 01 for the course introduction and Lecture 02 for MATLAB fundamentals.
2. Work through Lectures 03–06 to establish signal and system concepts.
3. Study Lectures 07–10 for convolution and transform-based analysis.
4. Complete Lectures 11–12 for sampling and discrete-time signal operations.
5. Solve the exercises in the lecture slides and reproduce relevant plots and calculations in MATLAB.

### Learning goals

Working through the lecture materials supports the ability to:

- Represent, classify, and manipulate continuous-time and discrete-time signals.
- Distinguish signal symmetry, periodicity, energy, and power.
- Classify systems using causality, linearity, time invariance, stability, memory, and invertibility.
- Analyze LTI systems using convolution.
- Apply Fourier series, Fourier transforms, and Laplace transforms to signal and system analysis.
- Explain the sampling theorem and carry out basic discrete-time signal operations.
- Use MATLAB for matrix operations, computation, and signal plotting.
